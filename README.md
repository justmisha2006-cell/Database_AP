# 🏢 ESP32 Resident Database — Pro Edition v2

[![ESP32 Framework](https://img.shields.io/badge/ESP32-Arduino--Core-blue.svg)](https://github.com/espressif/arduino-esp32)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Storage](https://img.shields.io/badge/Storage-LittleFS-green.svg)](https://docs.espressif.com)

Повнофункціональна автономна система управління базою даних мешканців, автомобілів та контактних телефонів для багатоквартирних будинків або житлових комплексів на базі мікроконтролера **ESP32**.

Система працює як локальна Wi-Fi точка доступу (SoftAP) з вбудованим HTTP-сервером, авторизацією (Basic Auth), захистом за допомогою PIN-коду та сучасним веб-інтерфейсом (Single Page Application).

---

## 🚀 Основні можливості

### 🌐 Веб-інтерфейс та чутливість (UX/UI)
* **Темна та світла теми** — перемикання в один клік з збереженням налаштувань у `localStorage`.
* **Компактний режим** — зменшення відступів таблиці для зручного перегляду великих обсягів даних.
* **Адаптивний дизайн (Mobile-First)** — зручна робота як з ПК, так і з мобільних пристроїв.
* **Інтерактивні картки** — швидке копіювання номерів авто кліком, дзвінки за телефоном (`tel:`) та перехід у WhatsApp (`wa.me`) в один клік.
* **Модальні вікна** для безпечного додавання, редагування, вилучення та налаштувань.

### 🔍 Пошук та Множинна Фільтрація
* **Миттєвий пошук (Ctrl+F)** за номером квартири, ім'ям мешканця, номером машини або телефоном.
* **Підсвічування совпадінь** у результатах пошуку (HTML `<mark>`).
* **Фільтри за категоріями:**
  * За під'їздами (Під'їзд 1 ... 6).
  * Без машин / Без телефонів.
  * Багатомашинні квартири (2+ авто).
  * Пошук дублікатів (однакові авто або телефони у різних квартирах).

### ⚙️ Функціонал Адміністрування
* **Керування воротами/шлагбаумом** — кнопка відправки імпульсу на реле прямо з шапки інтерфейсу.
* **Масове видалення** — зручний список із чекбоксами для вилучення кількох квартир одночасно.
* **Автоматична перевірка дублікатів** під час введення нових даних з підказками.
* **Пагінація** з можливістю вибору кількості записів на сторінці (10, 25, 50, 100).
* **Гарячі клавіші:**
  * `Ctrl + F` — швидкий перехід до пошуку.
  * `N` — відкрити модальне вікно додавання запису.
  * `B` — відкрити модальне вікно резервного копіювання.
  * `Esc` — закрити будь-яке модальне вікно.

### 💾 Резервне копіювання та Логування
* **Експорт у CSV** (формат, сумісний з Excel).
* **JSON Бэкап** — завантаження та відновлення всієї бази даних.
* **Об'єднання баз (Merge)** — розумне злиття завантажуваного бэкапу з існуючою базою без втрати унікальних даних.
* **Журнал подій (System Logs)** — перегляд та вивантаження логів системи в текстовий файл `.txt`.
* **PIN-захист** критичних дій (повне очищення бази даних, очищення логів).

## 🛠 Технологічний стек

* **Hardware:** ESP32 (NodeMCU, WROOM-32 тощо).
* **Firmware:** C++ / Arduino Core for ESP32.
* **Storage:** LittleFS (файлова система флеш-пам'яті), ArduinoJson v7.
* **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, Grid), Vanilla JavaScript (ES6+, Fetch API).
* **Security:** Basic HTTP Authentication, Administrator PIN confirmation.

## 📁 Структура збереження даних

Дані зберігаються у файлі `/database.json` у файловій системі **LittleFS** у наступній структурі:

```json
[
  {
    "flat": "кв. 415",
    "name": ["Іван Іванов", "Марія Іванова"],
    "cars": ["AA1234BB", "BC5678EX"],
    "phones": ["0931234567", "0507654321"],
    "flags": ["pod1", "pod2"]
  }
]

## 📡 Опис API Маршрутів (Endpoints)

| Метод | Маршрут | Опис |
| :--- | :--- | :--- |
| `GET` | `/` | Повертає головну HTML-сторінку зі скриптами та стилями. |
| `GET` / `HEAD` | `/get_data` | Отримання бази даних у JSON / Перевірка статусу з'єднання. |
| `POST` | `/add_data` | Додавання нового запису про квартиру. |
| `POST` | `/edit_data` | Оновлення існуючого запису. |
| `POST` | `/delete_flats` | Масове видалення квартир (JSON-масив номери квартир). |
| `POST` | `/restore_backup` | Повне перезапис бази даних з переданого JSON. |
| `POST` | `/merge_backup` | Об'єднання нової бази з поточною. |
| `GET` | `/get_logs` | Отримання системних логів ESP32. |
| `POST` | `/clear_logs` | Очищення логів (потрібен PIN-код). |
| `POST` | `/open_gate` | Відправка сигналу на відкриття воріт/реле. |

## 📥 Інструкція зі збірки та прошивки

### 1. Вимоги до середовища
* **Arduino IDE** (версії 1.8.x або 2.x).
* Установлений пакет плат **ESP32** (via Board Manager).
* Встановлені бібліотеки:
  * `WiFi.h` (вбудована)
  * `WebServer.h` (вбудована)
  * `LittleFS.h` (вбудована для ESP32)
  * `ArduinoJson` (версії 6.x або 7.x, доступна у Library Manager)

### 2. Налаштування параметрів
У коді програми задайте власні параметри авторизації та точки доступу:

```cpp
// Налаштування Wi-Fi Точки Доступу
const char* ap_ssid = "Database_AP";
const char* ap_password = "qwerty123"; // Мінімум 8 символів

// Логін та пароль для доступу до веб-панелі
const char* www_username = "admin";
const char* www_password = "admin";

---

### 3. Прошивка
1. Підключіть ESP32 через USB.
2. Виберіть потрібну плату (наприклад, `ESP32 Dev Module`) та відповідний COM-порт.
3. Оберіть схему розмітки пам'яті (Partition Scheme) з підтримкою **SPIFFS/LittleFS** (наприклад, `Default 4MB with spiffs` або `NO OTA (Large APP)`).
4. Натисніть **Upload** (Завантажити).

---

## 📲 Підключення та використання

1. Увімкніть ESP32.
2. На смартфоні або ПК підключіться до Wi-Fi мережі:
   * **SSID:** `Database_AP`
   * **Пароль:** `qwerty123`
3. Відкрийте браузер та перейдіть за адресою: **`http://192.168.4.1`**
4. Введіть логін `admin` та пароль `admin`.
